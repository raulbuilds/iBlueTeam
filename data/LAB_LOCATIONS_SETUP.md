# Lab network location configuration

`lab-locations.example.json` contains placeholder values for demonstration only. Copy it to `lab-locations.json` for local configuration, then replace `network` with your own lab network CIDR, `lat` and `lon` with the approximate location you want displayed, and `label` with a descriptive name. Do not commit private infrastructure details.

Example network `192.0.2.0/24` is documentation-only and is not intended to represent a real deployed network. The coordinates `0.0, 0.0` are placeholders.
